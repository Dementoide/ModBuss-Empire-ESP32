# Rika RK520-02 — Temperatura, humedad y EC de suelo

**Estado:** verificado en placa el 2026-11-16 (ID, baudrate, temperatura y cambio de ID). Humedad y EC solo al aire (valen 0), sin probar con estímulo. El cambio de ID rige al instante, sin reiniciar.

| Parámetro | Valor |
|---|---|
| Baudrate | 9600, 8N1 |
| ID por defecto | 1 |
| Función de lectura | F03 |
| Cambio de ID | F06 en el registro 0x0200 (512) con la nueva ID. Ej. a ID 2: `01 06 02 00 00 02 09 B3` (responde eco). Rige al instante (el manual pide reiniciar, pero no hace falta). |

| Reg | Variable | Tipo | Conversión |
|---|---|---|---|
| 0 | Temperatura | s16 | ×0,1 → °C |
| 1 | Humedad del suelo | u16 | ×0,1 → % |
| 2 | EC | u16 | ×0,001 → mS/cm (crudo = µS/cm) |

Lectura de los tres: `01 03 00 00 00 03 05 CB`.
